# METTPAD

Launch a coin on Meteora, keep the tax.

## The idea

A launchpad where anyone can start a coin on Meteora in a few steps, and the creator keeps a share of the trading tax instead of handing it all to the platform. Every coin gets its own page with a live chart.

## Main screens

- Home: the newest coins and a screener
- Launch: name, image and settings for a new coin
- Coin page: price chart and coin details
- Fees: what each coin has earned

Front end only. The backend, wallets and live data are not in this repo, and every address is a placeholder.

## Run it

```
npm install
npm run dev
```

Live site: https://mettpad.com
